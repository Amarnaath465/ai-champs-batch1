## 2. Connect Copilot to Jira via MCP

You have two supported paths — pick whichever matches your Jira deployment. **Do not guess tool names from this document once you're connected — the exact tool list your client shows you after connecting is the source of truth**, exactly like Module 04's warning about Spec Kit's CLI output.

### Path A — Atlassian's Remote MCP Server (Jira Cloud, recommended)

Atlassian hosts an official remote MCP server for Jira Cloud and Confluence Cloud, authenticated via OAuth — no server to run yourself. In VS Code, add it as an MCP server (Command Palette → **MCP: Add Server**, or edit `.vscode/mcp.json` in your workspace):

```json
{
  "servers": {
    "atlassian": {
      "type": "http",
      "url": "https://mcp.atlassian.com/v1/mcp"
    }
  }
}
```

Reload, then trigger the connection from Copilot Chat's MCP panel — it opens a browser window for you to sign in and grant scoped access to your Jira site. Approve only the site(s)/project(s) you actually need for today.

### Path B — Self-Hosted Bridge (Jira Data Center / Server, or air-gapped environments)

If your organization runs Jira Data Center rather than Jira Cloud, use a self-hosted MCP-to-Jira bridge instead (your platform team may already run one — ask before standing up your own). Typical `.vscode/mcp.json` shape for a locally-run bridge:

```json
{
  "servers": {
    "jira": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "mcp-atlassian"],
      "env": {
        "JIRA_URL": "https://jira.yourcompany.internal",
        "JIRA_API_TOKEN": "${input:jira_token}"
      }
    }
  }
}
```

**Never commit a real token into `.vscode/mcp.json`.** Use VS Code's `${input:...}` prompt (shown above) or an environment variable your shell already has set — not a literal string in the file.

## 3. Confirm the Connection

In Copilot Chat, ask it to list the tools the Jira/Atlassian MCP server exposes. You should see a mix of **read** tools (search/get issues, list projects) and **write** tools (create issue, transition issue, add comment) — write down the exact names now; Exercises 2 and 5 will use them.

- [ ] At least one "search" or "get issue" tool is visible
- [ ] At least one "create issue" tool is visible
- [ ] At least one "transition"/"update status" tool is visible
- [ ] You know which Jira project key you'll create today's story in
